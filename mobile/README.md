# 이음오피스 안드로이드 (태블릿)

데스크톱 이음오피스의 편집기를 안드로이드 태블릿 앱으로 감싼 것입니다.
편집기 소스(`apps/*`)는 고치지 않고, 이 폴더의 "브리지"가 데스크톱의 PC 쪽 기능을
태블릿 저장소로 바꿔 줍니다.

## 지금 되는 것 (1단계)

- 홈: 내 문서 목록, 찾기, 새로 만들기, 파일 가져오기, 보내기(공유)·이름 바꾸기·삭제
- 마크다운 편집기: 열기·저장, 그림 넣기, Word(.docx)로 내보내기
- HTML 편집기: 열기·저장, 미리보기, HTML 파일 보내기
- 마인드맵 편집기: XMind 열기·저장, PNG·마크다운 개요로 내보내기

## 아직 안 되는 것

워드·엑셀·파워포인트·PDF 편집기, AI 기능, PDF 내보내기·인쇄, 문서 사이 위키 링크.

## 설치 파일 받기

`main` 브랜치에 올리면 GitHub Actions(`.github/workflows/android-apk.yml`)가 APK를 만들어
**android-latest** 릴리스에 `IeumOffice-Android.apk`로 올립니다. 태블릿 브라우저에서
그 파일을 눌러 받고 설치합니다(처음 한 번은 "출처를 알 수 없는 앱 설치"를 허용해야 합니다).

새 버전도 같은 방법으로 설치하면 기존 앱 위에 덮어 설치되고, 문서는 그대로 남습니다.
**앱을 삭제하면 앱 안의 문서도 지워지니**, 중요한 문서는 홈의 "보내기"로 따로 보관하세요.

> 릴리스는 자기 계정으로 포크한 저장소에서 만드세요. 원본 저장소에 이 릴리스가 생기면
> 데스크톱 앱의 업데이트 확인이 이 릴리스를 보게 될 수 있습니다.

## 직접 빌드하기 (개발자용)

```
npm ci --ignore-scripts        # 저장소 루트
cd mobile
npm ci
npm run build                  # www/ 에 홈과 편집기 3개를 빌드
npx cap sync android
cd android && ./gradlew assembleDebug
```

## 서명 키

`android/app/ieumoffice-shared.keystore`는 덮어 설치가 되도록 모든 빌드에 같은 키를 쓰기
위한 개인 배포용 키입니다. 스토어에 올릴 때는 비공개 키로 바꾸세요.
